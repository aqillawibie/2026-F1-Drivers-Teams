🏎️ F1 Teams & Drivers

A beginner-friendly Formula 1 website showcasing the current F1 teams and drivers. Users can explore different teams, view their logos, and visit dedicated pages for more information.

🌐 Live Website

[[View the Website](http://127.0.0.1:5500/F1%20Drivers%20Website.html)
📖 About the Project

I created this project as one of my first web development projects while learning the fundamentals of HTML and CSS.

The website is focused on Formula 1, one of my biggest interests. It provides a simple way to explore the teams and drivers on the current F1 grid while allowing me to practice building and designing a website from scratch.

🎯 Project Goals

The main goals of this project are to:

* Practice writing HTML
* Learn the fundamentals of CSS
* Understand how Flexbox works
* Practice using images and hyperlinks
* Create a clean and organized website layout
* Learn how to structure multiple web pages
* Improve my web development skills through a topic I enjoy

🛠️ Tech Stack

* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, colors, and animations
* **Flexbox** — Organizing team cards and logos
* **Git & GitHub** — Version control and website hosting
* **GitHub Pages** — Deploying the website

✨ Features

* 🏁 F1 team overview
* 👨‍🏎️ Driver information
* 🖼️ Team logos
* 🔗 Navigation between team pages
* 🎨 Team-based colors and styling
* 🖱️ Hover effects
* 📱 Organized and responsive layout


📚 What I Learned

While creating this project, I learned how to structure a webpage using HTML and style it using CSS. I also learned how to use Flexbox to arrange multiple elements in rows, how to add hover effects, how to link different HTML pages together, and how to organize images and other website files.

This project helped me understand that building a website is not just about writing code, but also about organizing information and designing a good user experience.
